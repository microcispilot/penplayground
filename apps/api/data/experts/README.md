# Expert catalog

Copied from Simurgh's platform catalog (schema 2.0.0, 105 active personas) on
2026-09-16 and projected onto `@pen/contracts` `Expert`. Portraits are the
per-cell WebP variants (w192/w384). `voiceId` is the catalog voice profile id
(af_heart, am_adam, …); the deployment maps it to a Fish reference id via
`PEN_VOICE_MAP` (see `apps/api/src/config.ts`). Legends are premium voices.
